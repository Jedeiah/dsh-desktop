# DSh Desktop 手工回归清单

瘦壳重设计（v0.3）发版前手工回归。每项记录：✅ 通过 / ❌ 失败 / ⏭ 跳过（注明原因）+ 备注。

环境：macOS（arm64 本机）为主；Windows 项需 Windows 机器/虚拟机。App 构建后从 `.app` 包内运行（或用 `cargo tauri dev` 开发模式）。

## 1. 首次引导安装

| # | 场景 | 步骤 | 预期 | 结果 |
|---|---|---|---|---|
| 1.1 | 全新安装（无闭包） | 清空 `<app-data>/com.dsh-desktop.app`（备份后删），启动 App | 出现引导页（不启动 dsh 进程）；默认「安装最新版（latest）」 | |
| 1.2 | 默认安装 latest | 引导页点「安装」 | 显示下载/安装进度（npm 实时输出）→ 双重自检 → 自动进入工作台（dsh web UI 正常） | |
| 1.3 | 指定版本安装 | 引导页展开高级选项 → 选择指定版本（如上一版 rc）→ 安装 | 安装该指定版本；dsh 页「当前版本」显示该版本 | |
| 1.4 | 断网/失败重试 | 断网后启动 → 引导页安装 | 显示错误 + 重试按钮，提示检查网络；恢复网络后点重试成功 | |
| 1.5 | 安装中取消 | 安装进行中点「取消安装」 | 安装终止、tmp 清理；引导页可再次安装；`<app-data>/dsh/` 无残留 `-tmp` 目录 | |
| 1.6 | 引导页 registry 换源 | 高级选项填 `https://registry.npmmirror.com` → 安装 | 安装走该源成功；dsh 页 Registry 源显示一致 | |
| 1.7 | 已安装再启动 | 1.2 完成后重启 App | 不出现引导页，直接加载工作台 | |
