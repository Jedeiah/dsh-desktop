> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已确认的 OpenDesign v4 高保真稿（命令面板 + 管理抽屉 + 任务中心/Toast + 官方同源视觉）落地到现有 Tauri 壳页，功能一个不少。

**Tech Stack:** Tauri 2.11.5（unstable）/ vanilla HTML+CSS+JS（WKWebView + WebView2 双内核，无框架）/ Rust（仅改 1 个常量 + 4 个测试断言）。

### v4.1–v4.4 设计迭代定稿摘要（落地必须遵守，均已通过 DOM 实测）

以下变更在交互稿审核中逐步确认，已合入设计稿当前版（全部经过 chrome-devtools DOM 实测，双视口 1512×772 / 700×340 验证）：

1. **Registry 源常驻面板 → 弹窗化**：dsh 区「版本列表」面板 head 右侧为 `#btnRegistry`（link-btn「Registry 源设置」），点击打开 `#registryModal`（独立 modal，含 `#registryInput` 输入框撑满 100% 宽 + 取消/保存）；**不再有** 内联 `regInput/btnSaveReg/regStatus` 表单。
2. **版本联动行**：setup 主区新增 `#setupVerDisplay`（「将安装版本 **v0.21.0** · 可在高级选项更改」，`setupVerShow` 是 mono 版本号），与高级选项内版本选择双向联动；`#verManual` 手输也联动。
3. **版本选择 = 自绘 cselect（照搬现有 shell 实现，不引原生 select）**：`#setupVerWrap > #setupVerTrigger + #setupVerMenu`，与现有 `shell.html/shell.js/theme.css` 的 `setupVerWrap/setupVerTrigger/setupVerLabel/setupVerMenu` **同名同类**，落地时**直接复用现有 shell.js 已有逻辑**，仅做设计稿一致的视觉 token 化。菜单 `max-height: 240px; overflow-y: auto`（版本多时可滚动）、点击外部/Esc 收起、Enter/Space 展开、默认选中第一项=最新版。设计稿中显式折叠规则：`.adv:not([open]) .adv-body { display: none !important; }`（某些环境 UA 折叠规则失效，需显式声明）。
4. **高级选项交互**：`<details class="adv">` 折叠（CSS 显式控制）；setup 卡片**自身不滚动**（无 max-height/overflow），滚动在 `.setup-overlay`（`display: flex` + 卡片 `margin: auto` 居中，内容超高时滚动可达）。
5. **插件输出惰性显示**：`#pluginLogEmpty` 空态 div（「暂无操作记录 · 安装或卸载插件后显示实时输出」）+ `#pluginLog` 初始 hidden；有输出时显示日志、隐藏空态；`#btnClearLog` 清空。
6. **插件卸载 modal 确认**：列表行卸载按钮 → `openModal`（标题「卸载插件」、消息、danger 红钮「卸载」）→ 确认后执行 `plugin_op {op:'remove'}`。
7. **卸载区卡片化 + 按钮展开**：关于区卸载面板 head 为 `#btnToggleUninstall`（danger-ghost「卸载应用…」）→ 点击展开 `#uninstallZone`（原本 hidden），内含两行 `.uninstall-row` 卡片（`.opt-icon` 图标 + 标题/描述 + `#btnUninstallKeep`/`#btnUninstallWipe`），再点收起。
8. **关于页更新按钮一行**：「检查更新 / 下载并安装更新 / 在浏览器打开下载页」三按钮同一 btn-row（`flex-wrap: wrap` 容错）；面板紧凑排列，**不做** margin-top:auto 沉底（曾引入又移除——308px 空白观感差）。
9. **版本列表操作全弹窗 + 操作中文案**：每行按钮（安装/切换/回滚）点击先 `openModal` 二次确认（文案按 op 区分：install/switch/rollback 三类 OP_MSG），确认后执行 `applyVersion(v, btn, op)`；执行中文案：安装中…/切换中…/回滚中…/更新中…；回滚行判定 rollbackTarget（低于当前版本的已安装最高版本）。
10. **面板紧凑化**：panel padding 12px 16px、`.panel` 间 margin 10px、table td padding 6px 8px、banner padding 9px 12px。
11. **抽屉 flex 布局**：`.drawer-body` flex column + `overflow-y: auto`；`.drawer-section.active` 用 `flex: 1 0 auto`（**不要** `min-height:100%`——滚动容器内塌陷 32px 的坑）；插件区输出面板 `.panel:last-child { flex: 1 }` 吸收剩余高度（`.log` 随之变大、`min-height: 120px; max-height: none`）。
12. **inline-form 防换行**：`.inline-form { flex-wrap: nowrap }`、`.input { flex: 1; min-width: 0 }`、`.btn { flex: none; white-space: nowrap }`（安装/卸载按钮锁同行）。
13. **细节折叠显式化**已并入第 3 条：`.adv:not([open]) .adv-body { display: none !important; }`。
